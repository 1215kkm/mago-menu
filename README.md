# MAGO

탐색기에서 **Shift 를 누른 채 파일을 끌면** 커서 둘레에 원형 메뉴가 뜨는 Windows 프로그램.

- 칸에 놓으면 원본 옆에 바꾼 파일이 생깁니다 — PNG · JPG · WEBP · 정사각(SNS 1080) · 1MB 이하 · wav ↔ mp3 · PDF → 그림. 원본은 그대로입니다.
- 오른쪽 아래 **쓰레기통**에 놓으면 냠냠 먹고 윈도우 휴지통으로 보냅니다 (휴지통에서 되살릴 수 있어요).
- 많이 먹이면… 숨은 메뉴가 열립니다.

## 설치
[최신 릴리스](https://github.com/1215kkm/mago/releases/latest)의 `mago-setup.exe` 를 받아 실행하세요. 이후 업데이트는 자동입니다.

## 개인정보
파일은 PC 밖으로 나가지 않습니다. 인터넷은 두 가지에만 씁니다: 이 저장소의 숨은 메뉴 내용(`content/content.json`) 받기, 새 판 확인(GitHub 릴리스).

## 개발
`CLAUDE.md` · `HANDOFF.md` 참고. 숨은 메뉴 글 고치기는 `content/README.md`.
